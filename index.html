VPN SETUP TUTORIALS

Follow these step-by-step guides to configure your VPN applications easily.

1. Setting Up Exotic Tunnel & Exotic Fast VIP

  1. Download and install the app from the link above.
  2. Open the application and tap on Account / Credentials in the menu.
  3. Enter the Username and Password sent to your WhatsApp.
  4. Select your preferred server location and tap CONNECT.

2. Setting Up HTTP Custom

  1. Download HTTP Custom from Google Play Store.
  2. Download the configuration file (`.hc`) provided by our WhatsApp support team.
  3. Open HTTP Custom, tap the + (Plus) button, and select Open Config.
  4. Choose the downloaded file, check Use Payload / SSH, and click CONNECT.
